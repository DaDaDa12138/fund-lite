## 0. 范围与样本

- universe：`债券型` 与 `指数型-固收`（债券指数/ETF/联接），共 8,141 个**份额**（2026-11-03）；
  同一基金的 A/C/D/E 等份额按 `family_id` 归并，但筛选先按份额跑，再在榜单层折叠。
- 不纳入：QDII 债基 166 只、偏债混合 1,475 只（200 只试点 1 年 MDD 中位 4.96%，
  债基 8 条固定线仅 2/196 全过，见 `docs/hybrid-pilot-2026-11.md`）。
- 业务日：`business_date`；但净值与指标另有 **有效净值日 `nav_as_of`** 与 **指标日 `metric_as_of`**。
  `nav_as_of` 是回看 14 天内覆盖率 ≥90% 的最新净值日；`metric_as_of` 是 365 天指标实际算到的日期。
  规模、费率、申赎状态、经理、风格取 `<= nav_as_of` 的最近快照；风格标签是当前文本/持仓推断，回测存在前视，见 §12。
- 2026-11-03 起，`business_date` 可以晚于 `nav_as_of`（例如业务日 11-03、有效净值日 11-02）；
  榜单/API/CSV 必须同时展示三者，不能把 `MAX(nav_date)` 当市场日。
- 指标窗口：1 年 = 365 天、3 年 = 1095 天、5 年 = 1825 天；窗口内有效年数来自
  `fund_metric.years`，不是成立年限。3 年覆盖 ≥90% 才标 `is_full_3y=1`。

## 1. 执行层 L1–L9（L10 为输出层）

| 层 | 内容 | 失败处理 |
|---|---|---|
| L1 | 身份 `ok`、成立日存在、有 NAV、净值新鲜度 ≤10 天、365 天年化存在、**p75 采样间隔 ≤7 天**、metric 可比性旗标为空、**指标日 ≤ 有效日（否则 `metric_lookahead`）；指标日早于有效日 ≤7 天容忍并记 `metric_stale_days`，>7 天记 `metric_stale_gt_7d`** | 退出，记原因码 |
| L2 | `buyable_state == confirmed_yes`；场内 ETF/LOF 的“场内交易”单列 `exchange_traded` | 退出正式榜；质量达标者进观察榜 |
| L3 | `effective_days > 90`，或 `lockup_type` 为 `periodic_open/closed` | 退出正式榜；质量达标者进受限榜 |
| L4 | family 规模、目标份额规模、持有 1 年总成本三项均可验；规模/份额取 `report_period <= as_of-45 天` 的最近一期（P0-5） | 退出，记 `*_missing`；只有 `profile_current` 的基金正式榜另记 `scale_pit:not_pit` |
| L5 | 成立 ≥1 年；family 规模按年限分档；**目标份额 ≥0.5 亿**。正式榜另要求 **3 年完整业绩**（见 L6C/L6E） | 退出 |
| L5.5 | 持有 1 年总成本 ≤1.30% | 退出 |
| L6C | 稳健风格 9 项固定线（含 **3 年完整业绩**）+ L6D 单一原因缓释（生产关闭） | 不通过 → 不进正式榜；1–3 年者走新锐榜 |
| L6E | 增强风格相对准入 + 7 项严格口径至少 5 项 + **3 年完整业绩** | 不通过 → 不进增强榜 |
| L7 | 动态分位（综合分无条件 q70 与固定线取 max + 其余 6 项至少 5 项；批次冻结 + 双侧滞回） | 不通过 → 不进正式榜 |
| L8 | 数据质量分（只展示）+ 经理职业年限 ≥365 天 + **现任经理在本基金 ≥365 天** | 经理不足 → 退出 |
| L8R | 独立风险门：持仓集中度 + 累计净值压力测试（2022Q4/2020H1/2016Q4/近5年最差60日） | block → 退出正式榜（L8R），watch/unknown 只展示 |
| L9 | 排序、family/公司折叠、风格 cap、配额 | 输出八榜（正式/观察/研究） |

### 1.1 独立风险门（P0-3）

- 纯债/短债/信用债：前十大 >90% 或单一债券 >25% 或单一信用发行人 >25% 或信用前三大 >45% 或可转债 >5% 或股票 >5% → block；前十大 >75%、单一 >15%、单一发行人 >15%、前三大 >30%、转债 >3%、股票 >2% → watch。
- 利率债/指数：前十大 >120%、单一 >60% → block；>100%、>35% → watch；持仓缺失允许 unknown，不因政策金融债天然集中而误杀。
- 增强债：前十大 >95%、单一 >35%、信用发行人 >35%、转债 >40%、股票 >20% → block；更严的 watch 档见 risk_gate.py。
- 压力测试：2022Q4 纯债 <-3%、增强 <-5%；近5年最差60日纯债 <-4%、增强 <-8% → block。2016Q4/2020H1 也纳入；历史最差60日只作 watch 证据。
- 纯债/短债/信用债/增强债无持仓 → block（不能证明集中度与含权暴露）；利率/指数无持仓 → unknown，不静默放行也不误杀。
- 持仓报告期距 as_of 超过 270 天按陈旧处理：返回空持仓并 block（不再把 2021Q3 的旧持仓当最新一期）。
- 全部压力收益用 acc_nav；unit_nav 的分红/拆分会造成假暴跌（006431 2022-12-12 是典型）。

> 生产 run 的层级计数是“最终停留层/退出层”的数量，不是“曾经到达该层”的数量；
> 例如 L2 1,793 表示 1,793 只在 L2 可投性检查退出，L9 154 表示通过全部门禁的数量。

## 2. 规模、份额与费率

### 2.1 规模

- family 规模分档（长期）：成立 1 年 2.0 亿、2 年 2.0 亿、3 年 2.5 亿、4 年 3.0 亿、5 年 3.0 亿。
- 中短债：固定 1.5 亿。
- 目标份额：L5 要求 `share_class_scale_billion >= 0.5` 亿；核心 50/收益精选 10 要求 ≥2.0 亿。
- 数据来源：`fund_profile.field_src_json.share_class_scale_billion`；
  `fund_profile.share_scale_billion` 目前全 NULL，不再使用。
- 为什么两者都要：family 规模回答“基金公司会不会清盘”，份额规模回答“这一份能不能买、
  会不会被大额申赎摊薄”。只按 family 汇总会让 1.58 亿的 C 份额靠 9.56 亿 family 进核心榜。

### 2.2 费率

- 口径：**持有 1 年总成本** = 持续计提费（管理 + 托管 + 销售服务）
  + 申购费有效值 ÷ 1 年；申购费有效值 = 申购费率上限 × 0.1（第三方 1 折）或 ×1.0（无折扣）。
- 赎回费按“持有满 1 年免收”处理，不进入门槛；阶梯表只做展示与 `/cost` 情景。
- L5.5 硬天花板 1.30%（全市场约 p98），只清异常尾巴；
  主要约束在 L6C 固定线 0.90% 与 L7 动态 q85。

## 3. 固定质量线（L6C，稳健风格）

9 项硬比较，全部通过才进入 L7：

| 项 | 门槛 |
|---|---|
| 综合分 | ≥62.0（P0-3 配额校准） |
| 1 年年化 | ≥2.0% |
| 1 年 Sharpe | ≥0.8 |
| 1 年 Calmar | ≥2.8 |
| 1 年非负日占比 | ≥70% |
| 1 年 MDD | ≤2.0% |
| 1 年 Vol | ≤6.0% |
| 持有 1 年总成本 | ≤0.90% |
| 3 年完整业绩 | 3 年窗口有效年数 ≥90%（is_full_3y） |

- **3 年完整业绩是显式门槛**（P0-2）：此前它只是 composite 的隐含后果——
  3 年覆盖不足时 long_core=0，综合分上限 40，永远过不了固定线 62。现在把
  “正式榜只收 3 年以上”写成可解释的检查项，1–3 年基金不再被静默判死，
  而是进入 bond_rookie（新锐榜，1 年权重）。
- 规模不在固定线重复判：L5 已按 family 年限 + 份额规模判过一次。
- 缺失值一律不通过（`missing`），不做“缺失按 0 分但继续算”的静默放行。
- L6D 缓释：恰好一项失败、且差距在边界内、综合分足够高时放行；
  增强债不适用。P0-1 前实测 992 次检查仅 1 条放行（011961，年化差 0.0216pp），
  且 `composite≥80` 在债基分布中几乎不可达；P0-3 起生产关闭（`relief_enabled=false`），
  代码保留为研究保险丝，不作为可信度证据。

## 4. 动态分位（L7）

- **母体**：通过 L1–L5.5 的**可投域**（`PERCENTILE_POOL=investable`）。
  不含 L1 无指标、L2 不可申购、L3 长锁定/定开、L4 缺资料、L5 不成熟/太小者。
- **风格内分位**：同风格样本 ≥15 才用风格分布，否则回退同一母体的全局分布并标 `fallback`。
- **winsorize**：5–95%，只用于估阈值。
- **7 个动态字段**：综合分 q70、1 年年化 q55、Sharpe q50、Sortino q50、Calmar q50、
  非负日占比 q45、费用 q85。MDD/Vol 不进入动态层（与 Calmar 共线，且固定线已覆盖）。
- **综合分阈值必须无条件估计**（P0-3）：在完整动态母体上取 winsor 5–95% 的 q70，
  再与固定线 62 取 `max(62, q70)`。旧实现先筛 `composite≥58` 再取 q70，是条件分位，
  q70 被 58 锚死，池子结构一变通过率就漂移。若 `q70<62`，记 `dynamic_inactive=true`，
  明确表示动态综合分线没有额外选择性，而不是假装它在工作。
- **固定线 62 的来历**：2026-11-02 批次全门槛池（3,033 只）composite q84≈63.59；
  取整数 62 约等于“可投域前 16%”。这是**配额/选择性参数**，目标正式榜 120–160，
  不是收益预测线；不得把“过 62”解释成未来收益保证。
- **合成规则**：收益类阈值 = `max(风格绝对底线, 分位值)`；费用 = `min(风格绝对上限, 分位值)`。
- **判定**：综合分必须过上述阈值；其余 6 项至少 5 项过线（`composite_and_k_of_n`，k=5/6）。
  这是把“9 项独立分位相乘”换成“综合分硬门槛 + 多数项相对不差”，避免联合概率塌缩到 0.2%。
  P0-3 实测（run 20261104T002125-screen-04da61）：fixed pass 被动态门挡 23 只，
  全部是 k=5 不足，`fixed_pass_blocked_composite_only=0`；L7 23 条。k=5 真实咬合，
  不再是 k=4 下“只失败 composite”的伴随项。
- **binding 统计**：每轮把各动态维度的失败次数写入
  `reports/screen/<run_id>/dynamic_binding.json`，并区分“全母体”与“固定线已过者”。
  只有后者能说明动态门真的改变了结果；若长期只有 composite 失败，应删掉 6 维规则或改 k=6，
  而不是继续宣称“7 维动态门”。P0-3 起 k=5，binding 统计写入 `dynamic_binding.json`。
- **缺失阈值不再免检**：`threshold_unavailable` 按失败处理，并计入 binding 统计。
- **批次冻结**：同一 `batch_id` 第一次跑批把阈值写入 `screen_threshold`；同日重跑读冻结值。
  首次冻结后 run 标 `frozen=true`，避免“阈值已写但本轮仍用内存值”的歧义。
- **滞回**：只对上一批正式榜成员生效；新进入者仍用 enter 线。观察/受限榜不续命。
- **已知封顶**：Sortino 封顶 10、Calmar 封顶 20 会让分位阈值卡在封顶值；
  `fund_metric.raw_sortino/raw_calmar` 留痕，后续可改用 raw 值估阈值。

## 5. 增强债独立准入（L6E）

增强风格不走稳健榜的 9 项固定线 + 动态分位，而是：

1. **相对准入**：同风格分位（年化 q60、Calmar q60、Sharpe q50、正收益 q45、
   MDD q75、Vol q75、费用 q85）+ 绝对地板 + 正式分 ≥55。
2. **严格口径叠加**：原 7 项绝对检查至少通过 5 项（`enhanced_strict_min=5`）；
   不通过时 `strict_overlay=below_min`，决策页显示通过项数。
3. **年化混合**：1 年与 3 年年化各 50%；3 年缺失时退回 1 年并标 `1y_only`，不静默冒充 3 年。
4. **配额**：每风格 ≤40、增强榜合计 ≤110。

增强债不进入稳健榜动态母体；否则转债/二级债的高波动会抬高清债的分位线。

## 6. 评分

所有分数都是**同风格、同批次内的百分位**（0–100），不是绝对收益预测；
跨批次不可直接比较，跨风格也不可直接比较。

### 6.1 短期核心（1 年窗口）

`return_1m .20 / return_3m .20 / Sharpe .30 / Sortino .15 / Vol(负) .15`

### 6.2 长期核心（3 年/5 年窗口）

| 项 | 权重 |
|---|---|
| 3 年年化 | .22 |
| 3 年非负日占比 | .13 |
| 3 年 MDD（负） | .18 |
| 3 年 Vol（负） | .10 |
| 3 年 Calmar | .10 |
| 5 年 MDD（负） | .12 |
| 3 年 Sortino | .05 |
| 1 年 Calmar | .05 |
| 1 年 MDD（负） | .05 |

- 3y+5y 风险权重合计 **50%**；1 年风险只作辅助。
- `is_full_3y` 为假，或长期权重覆盖 <60% 时，`long_core=0`；
  同时 L6C/L6E 的 `history_3y` 检查会显式失败（P0-2），这类基金走
  新锐榜/观察，而不是被“缺失按 0”静默判死。
- 5 年 MDD 只有在 `is_full_5y` 为真（5 年覆盖 ≥90%）时才按 0.12 计权；
  3.1 年的 MDD 不能冒充 5 年风险，不足时该项置空并在剩余维度重归一化。
- 缺失项在长期分内**重归一化**（只在可用维度上归一），并返回 `long_core_weight` 覆盖比例。

### 6.3 综合分与正式分

- 综合分 = `0.40 × short_core + 0.60 × long_core`。
- 短期正式分：6 月 .16 / 1 年 .14 / 1 年年化 .14 / Sharpe .14 / Sortino .12 /
  1 年 MDD .10 / 1 年 Vol .10 / 1 年非负日占比 .10。
- 长期正式分：1 年年化 .12 / 3 年年化 .10 / 1 年收益 .08 / 3 年收益 .05 /
  Sharpe .08 / Sortino .06 / Calmar .08 / 1 年 MDD .04 / 3 年 MDD .12 /
  3 年 Vol .08 / 3 年 Calmar .10 / 非负日占比 .04 / 费用 .03 / 规模 .02。
- 正式分 = `0.45 × short_formal + 0.55 × long_formal`。
- 排序分 = `0.85 × 综合分 + 0.15 × 6 个月收益分位`；只影响展示顺序，
  不参与固定线/动态线/经理门禁。

## 7. 榜单、配额与折叠

| 榜 | 准入 | 配额/上限 |
|---|---|---|
| `bond_stable` | 稳健风格过 L6C + L7 + L8 | 正式候选池 ≤320；两正式榜各 ≥25% |
| `bond_enhanced` | 增强风格过 L6E + L8 | 每风格 ≤40、合计 ≤110 |
| `bond_core` | 正式候选按排序分跨风格精选 | 50；只收 pure/short/credit/rate/index；增强=0、转债=0；short≤10、credit≤6、rate≤4、index≤6；份额≥2 亿、经理 tenure≥730 天、is_full_3y |
| `bond_core10` | 同一排序分再集中；贪婪相关性分散 + 有界单换 | 10；同样只收稳定风格；short≤2、credit≤2、rate≤1、index≤1；其余给 pure；每轮选 `rank_score − 50×max_corr`，硬拒绝 max_corr>0.85；选满后再做最多 3 轮单换，只接受排序分损失≤2 且有效 bet 提升≥0.005 |
| `bond_long` | 正式候选 + 3 年完整 + 5 年覆盖≥60% 且 5 年年化非空 + 份额≥2 亿 + 经理 tenure≥730 天且覆盖 3 年窗口≥80% | 20；影子观察榜，不替换稳健/增强，不参与正式配额；按 long_score 排序 |
| `bond_watch` | L2 不可申购但质量达标 | 只展示，不占正式名额 |
| `bond_locked` | L3 持有期/定开但质量达标 | 只展示，不占正式名额 |
| `bond_rookie` | 历史 1–3 年；只差综合分和/或 3 年完整业绩 | 30；新锐分 ≥60、数据质量 ≥70 |

折叠规则：

- 正式榜同一 family 只留 1 只（代表 = 总成本最低；平手取正式分最高）。
- 单公司上限 2 只（v10 从 3 降到 2）；核心榜同样适用。
- 核心榜/收益精选先按风格 cap 过滤，再 family/company 折叠，再补位；
  不会为了凑满 50 只而突破风格 cap。
- core10 的贪婪选样以 365 天共同披露日收益算两两相关；目标有效 bet≥1.8、最大相关≤0.85。选满后做有界单换（`CORE10_SWAP_MAX_SCORE_LOSS=2.0`、`CORE10_SWAP_MIN_GAIN=0.005`、最多 3 轮），不放松风格/家族/公司/相关约束；达不到 1.8 仍标 `downgraded`，不宣称分散化。
  1.8 是目标而非保证：当前可投池/风格 cap 下实测约 1.69，报告写实际值，不假装达标。
  core10 仍是 stable 的集中视图，10 只不是 10 个独立 bet。
- 核心榜要求 `is_full_3y`、份额 ≥2 亿、现任经理 tenure ≥730 天；
  不满足者留在稳健/增强榜，不“降级硬塞”。
- 长期核心观察榜（`bond_long`）另要求 `coverage_ratio_5y≥0.60` 且
  `has_5y_annual=true`；只有“窗口跨了 5 年”但 5 年年化为空的基金不能进榜。
  经理 tenure 还要求覆盖 3 年窗口≥80%（≥876 天），730 天只覆盖 66.7%，
  不足以证明 3 年业绩由当前团队创造。
  它是影子榜，报告/API 必须标“观察”，不能与稳健榜名次直接比较。

## 8. 数据质量与经理

- 数据质量分（0–100）：净值样本数（≥700 记 30）、最大披露间隔（≤3 天记 20）、
  新鲜度（≤5 天记 20）、指标完整度（≥10 项记 15）、资料完整度（≥3 项记 15）。
  只展示，不参与排序，不因缓释打折。
- 经理职业年限：现任经理中最短职业年限 ≥365 天；缺值默认放行，但写进决策证据。
- 经理任职：现任经理在本基金的最短任职 ≥365 天；核心榜 ≥730 天。
  缺值默认放行（`MANAGER_TENURE_REQUIRE_KNOWN=False`），但会在 `manager` 证据块中显示。
- 为什么两个都要：职业年限长不等于在这只基金任职久；“上任 6 天”不能代表当前策略的业绩。

## 9. 发布与契约治理

- `screen_batch`、`screen_run`、`publication` 都记录 `screen_contract`；
  `publication` 还记录 `formula_contract`。
- 同一 batch 首次冻结后，若再用不同 `SCREEN_CONTRACT` 重跑，直接抛
  `batch_screen_contract_mismatch`；不会出现“batch v9 / run v10”。
- 发布门禁：`blocked` 拒绝发布；`warning` 允许发布但写进 `summary.md`、API meta 与质量页。
  当前常态 warning：`board_drift`（换契约/收紧门槛）、`dynamic_boundary`、
  `forward_not_ready`、`valuation_unavailable`。
- `rank_score_order`（P0-6，block）：正式榜名次必须与 `rank_score` 严格一致；缺分或出现
  严格逆序即拒绝发布，并列分数不算逆序。报告同时展示排序分与正式分，并说明"正式分不
  参与排名"，避免把两套权重误读成排序错误。
- 报告首屏（P0-7）：固定写"这不是买入建议"；展示 `forward.summary` 的证据等级、前瞻
  cohort/成熟观测数；配置 `evidence.as_of` 与本次 `nav_as_of` 一致时才展示历史 IC/DSR，
  否则明确写"未登记匹配证据"，不能用旧证据冒充当前证据。
- `lifecycle_coverage`（P2-4，warn）：`fund_lifecycle` 为 0 行时提示“未导入清盘/合并样本，
  回测与前瞻仍含幸存者偏差”；有样本时显示清盘/合并只数。它只披露，不阻断发布。
- `dsr_skill`（P2-5，warn）：`evidence.dsr < evidence.dsr_threshold`（默认 0.95）时明确写
  “不能拒绝无技能原假设，报告只能写候选池”；高于门槛才允许“有选基技能”的表述。
- 报告 v2 第 6 节展示正式榜“风格 × 久期桶”（raw beta <0.25 短、0.25–0.75 中、≥0.75 长；
  覆盖<60% 或 R²<0.05 记未知），并披露同风格内久期跨度；桶只用于诊断，不改变准入。
- 发布 as-of 单调性（ADR-117，block）：`publish.commit` 比较新 run 与当前 publication 的
  `(nav_as_of, metric_as_of)`，新 run 更旧时抛 `publication_older_than_current`；只有显式
  `--allow-older` 才允许回滚。它防止“手工重跑 11-02 覆盖 11-03”的事故再次发生。
- 调度器（ADR-117）：`scheduler` 每轮用子进程执行 `python3 -m fundana daily --quiet`，不在长驻
  进程内直接调用 `daily.run`；代码、配置、迁移和公式契约每轮重新加载，避免旧进程过夜。
- 只读 API 缓存（ADR-117）：缓存 key 以当前 publication revision 开头，发布切换后自然失效；
  `/overview` 600s、`/quality` 300s、`/portfolio/diagnostics` 600s、`/decision` 600s。
  `/portfolio/diagnostics` 默认读发布时已写入 `report.json` 的组合段，缺失才回退重算；服务启动
  后后台预热，冷启动第一个请求不再承担全表统计。
- `screen_run` 记录 `nav_as_of`、`metric_as_of`、`freshness_json`；`publication` 也记录前两者。
  发布门禁用有效日判断：没有有效净值日、指标 blocked、`metric_as_of < nav_as_of` → 拒绝；
  指标 50%–90% 或局部最新日覆盖率不足 → warning。
- 发布产物包含 3y/5y 指标、覆盖字段、份额规模、经理 tenure；
  旧 publication 的 `screen_contract/formula_contract/nav_as_of/metric_as_of` 可能为 NULL，不可与新 publication 直接比换手。

## 12. 残余局限（必须随榜单一起披露）

1. **不是经过验证的“优质基金发现器”**：第三轮审计的 12 个季度队列代理验证中，
   v10 rank 对前瞻年化 IC 为 +0.011、对前瞻 MDD 为 −0.025；v10 预算年化 3.58%、
   MDD 1.65%，v9 为 3.75%、1.64%，基准 3.41%、1.55%。v10 只在 3/12 队列年化高于 v9，
   平均低 17.2bp；MDD 中位低 8.1bp 但均值高 1.2bp。缺少 point-in-time 风格、
   费率/份额/tenure 与清盘回补；当前证据支持“合格的风险过滤器/候选池生成器”，
   不支持“长期 alpha 发现器”。
2. **风格标签前视**：风格来自当前文本/持仓推断，回测用当前标签会给历史队列注入前视；
   分风格 IC 只能作方向性参考。
3. **幸存者偏差**：清盘基金未完整回补；规模门会先挡掉最可能清盘的小基金，
   因此榜单内部的偏差可忽略，但全样本 IC 的绝对值应下调。
4. **1 年窗口仍主导短期分**：v10 把长期风险权重提高到 50%，但 1 年数据仍是
   short_core/short_formal 的主输入；对 2022 年级别的债灾，1 年窗口仍可能低估尾部。
5. **核心榜是启发式风格预算**：short≤10、credit≤6、rate≤4、index≤6 来自风险预算，
   未做组合优化/协方差约束；core10 的 10 只也不是“10 只独立 bet”。
6. **经理数据覆盖不全**：tenure 缺失默认放行；新任经理的“旧业绩”仍可能被计入基金历史。
7. **摊余成本定开债**：P0-2 已把 amortized_cost/zero_risk/sparse_nav/stale_nav
   显式标记，并在 L1 与分位分布中隔离；原始 fund_metric 仍保留这些曲线，
   研究视图若绕过筛选引擎直接取指标，仍可能看到不可比样本。
8. **费率**：5 年成本与满 1 年赎回费已进 API/CSV/网页，但赎回费未进入门槛，也未按实际持有期分档；持有期 <1 年的实际成本可能高于 cost_1y。
9. **发布门禁的 board_drift 63.0%**：本次是 v10→v11 换契约 + 多轮收紧门槛导致的预期漂移，
   不能解读为“基金大面积变差”；下一批应回到正常换手区间再评估。
10. **长期权重修复未通过 12 队列复核**：3y/5y 覆盖与风险权重是结构性修复，
    不能据此宣称“更低回撤”；5 队列的“10–15bp 换 6–7bp MDD”已撤回。
    生产已进入 v11；v9 同池影子对照仍保留，但仍是当前分位、尚无成熟前瞻。
11. **v9 shadow 不是完整 v9 管线**：固定 v10 的 L9 通过集合与 core 约束，只替换
    v9 长期分/排序分；不覆盖被 v10 门槛挡掉的基金，当前分位也不是 PIT。首轮
    core10 重叠 6/10 只是选择差异，不是业绩证据。
12. **shadow 前瞻尚未成熟**：`shadow_forward` 已把 v9/v10 core10/core50 冻结到独立
    `shadow_*` 表，但首轮 cohort 的 240 条观测全部 `not_ready`；在至少 12 个决策月、
    ≥100 条成熟观测之前，不能据此讨论 v10→v9 切换。
13. **P0-1 只解决“输入可重放”，不解决“历史指标可重建”**：`screen_run_input` 冻结
    本次 run 看到的 37 列输入，规模/任职按 as-of 读；但 `fund_metric` 仍是当前契约的
    最新快照，历史 `--business-date` 的 `lookahead_metrics` 会大于 0。清盘名单仍需
    外部导入，导入前历史宇宙只有存续基金。
14. **P0-2 是可比性门，不是质量门**：摊余成本定开不是坏产品，只是不能和市值法
    债基比夏普；sparse_nav 的 3 天阈值是工程口径，周披露定开债可能被误伤。
    当前代价是锁定榜少 4 只，正式榜与 core10 不变。
15. **core10 不是 10 个独立 bet**：gen69 的 core10 平均两两相关 0.540、有效独立 bet 1.707，
    最大相关 0.804（006633/019161）；有界单换只带来 +0.031，仍不是 10 个独立 bet。榜单应按
    “一个债券 beta + 风格偏移”理解，不能按“10 只分散基金”做等权配置。
16. **统计显著性仍不足**：99d035 的 core10 相对 formal 池年化超额 0.2926%（95% CI
    -0.0038–0.5601），rf 调整后的 DSR 0.660（n_trials=256），5% 水平不能拒绝“无技能”；
    且只有 1 年窗口、基准含 core10 自身。上一版 c50c49 的 +0.574%/CI 0.297–0.825/DSR 0.72
    也没有通过 0.95，换一批数据后区间跨 0，更不能把样本内超额写成 alpha。
17. **数据健康是快照，不是独立冗余**：`data-health` 能发现 schema 漂移、净值过期、
    采集失败与单源域，但 directory/status/profile/scale/manager/fee 仍只有东财一个来源；
    nav/holding/validation 的“第二来源”也多数共用东财上游。通过检查不等于数据独立。
18. **前端证据仍有限**：5 年覆盖、份额规模、经理 tenure 与风险压力值已进榜单/悬停，
    但没有独立压力测试页；5 年覆盖为空不能读成 0，风险 watch/unknown 也不等于已排除风险。
19. **P0-5 的 45 天规模滞后是保守口径**：2026-11-02 的 cutoff=2026-09-18，最新可用
    报告期是 2026-06-30，而不是已披露的 2026-09-30；这会低估 Q3 规模增长，也会让
    少数新份额回退到 `profile_current` 并失去正式榜资格。45 天是“确保已披露”的
    工程保险丝，不是监管披露截止日；《公开募集证券投资基金信息披露管理办法》要求
    季报在季度结束之日起 15 个工作日内披露，45 天比法定窗口更保守，因此会漏掉
    已披露的 Q3。后续若要更贴近真实可得性，应接入公告日期，或把滞后缩到 30 天
    （仍留约 9 个自然日缓冲）并重跑基线。
20. **长期核心观察榜不是完整周期评级**：`bond_long` 只要求 5 年覆盖 ≥60% 且 5 年年化非空，
    仍允许最多 40% 窗口缺失；它按 `long_score` 排序，与稳健榜的 `rank_score` 不是同一把尺，
    不能把 long 名次与稳健名次直接比较。20 只里仍可能包含中短债，因为“长期”指证据长度，不是久期。
21. **跨榜 family 只披露、不自动去重**：同一 family 可能同时出现在稳健/核心/长期榜，
    报告给出唯一 family 数与重复数；把多榜重复当“多只独立推荐”会高估分散度。
22. **report v2 的 why/caveat 是规则解释，不是因果归因**：它引用固定线、3/5 年覆盖、
    经理 tenure、费用、风险门等已落库证据，不能说明“因为选了它所以未来会涨”；
    组合体检的相关矩阵基于共同披露日，样本不足时只展示可用对。
23. **core10 贪婪分散不是全局最优**：它按 `rank_score − 50×max_corr` 逐轮选样并硬拒绝 >0.85，
    不保证有效 bet 达到 1.8；当前池实测 1.691，报告写实际值。相关性只覆盖 365 天共同披露日，
    不能代表全周期或压力情景相关。
24. **久期/信用桶是诊断口径**：桶边界 0.25/0.75 与 0.10/0.60 是工程选择，不是监管分类；
    raw beta 来自 365 天三因子回归，利率 regime 变化时 beta 不稳定；unknown 比例高时
    不能把矩阵读成全样本分布。桶未进入筛选分或分位分组。
25. **季度快照不是完整 PIT 宇宙**：`fund_metric_snapshot` 是逐季重算，不是当时生产库原样拷贝；
    历史风格/费率/份额/tenure 仍是当前值，清盘样本未导入前仍只含存续基金。
    12 季回填可用于审计，但不能据此宣称“已完成 point-in-time 回测”。
26. **生命周期表仍为 0 行**：清盘/合并样本未导入，`lifecycle_coverage` 只 warning 披露；
    回测与前瞻的幸存者偏差没有校正。不能从“今天不在基金表里”反推清盘。
27. **DSR 0.660 仍是治理结论**：`dsr_skill` 在 <0.95 时只 warning，报告必须写“不能拒绝无技能”；
    DSR 假设正态、`n_trials` 是近似，0.95 是治理阈值，不是统计证明。
28. **榜单 API 是发布快照，不是实时净值**：`/rankings` 已钉住 run 的 `nav_as_of`/`metric_as_of`，
    不会读到发布后的下一交易日；`/funds/<code>` 详情页仍展示最新净值/档案，两者语义不同。
    要看最新净值，需等下一轮 screen/publish，而不是把详情页数字拼进旧榜单。
29. **API 缓存是单进程内存缓存**：多 worker 部署时各自一份；发布切换后按 revision 失效，
    但同一 revision 内的数据修正要等 TTL 过期或重启。缓存只服务只读接口，不影响筛选/发布。
30. **发布单调性只比较 as-of**：同一 `(nav_as_of, metric_as_of)` 的重复发布仍允许（用于修正产物），
    门禁不会判断两次产物哪份更好；回滚旧日期必须显式 `--allow-older`，并会在发布记录留痕。
