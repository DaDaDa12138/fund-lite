# 偏债混合能否并入债券筛选：200 只试点结论

**结论（TL;DR）**：**不并入**。偏债混合的风险剖面与债券基金不是同一资产类别：样本 1 年最大回撤中位 4.96%、年化波动 4.73%，分别是债券全库的约 16 倍和 7.8 倍；债基 8 条固定线在 196 只可评分样本中只有 2 只全过，真正同时过固定线与申赎门禁的只有 1 只。把偏债混合塞进债券 universe，不会扩大有效榜单，只会把“含权产品”混进“低波债基”的分位池。

- 试点日期：2026-11-02
- 样本：`混合型-偏债` 1,475 只中固定随机抽 200 只（seed 20261103）
- 可评分：196 只；有 1 年指标：163 只
- 采集 run：`20261103T083831-hybrid-pilot-f64b83`
- 复现：`python3 reports/analysis/hybrid_pilot/collect_sample.py --limit 200` → `python3 reports/analysis/hybrid_pilot/analyze_sample.py`

## 1. 问题

债券筛选的固定线、动态分位与七张榜都是按“债券基金”标定的。偏债混合（协会分类属混合型，不是债券型）能不能直接复用这套口径？如果能，就把 `universe.types` 扩到 hybrid；如果不能，就明确留在未覆盖范围，避免以后反复讨论。

试点只回答“口径是否适用”，不写 `screen_decision` / `screen_pick`，不发布正式榜。

## 2. 方法

1. 从最新 `src_directory`（2026-11-02）取 `type_text LIKE '混合型-偏债%'`，固定 seed 随机抽 200 只。
2. 逐只补采 NAV 历史、jbgk 画像、费率；只写 L1/L2 事实表，不写 `fund` 表，不进入债券 universe。
3. 用生产同款 `metrics_engine.compute_fund(..., dry_run=True)` 复算 365 天指标；用 `screen_engine.Candidate` + `score_candidate` + `fixed_checks` + `base_gate` 做影子评分。
4. 所有样本统一 `style_code='hybrid_balanced'`，在样本内做同风格分位；申赎状态固定 `confirmed_yes`，只看评分与固定线，不看可投性。
5. 规模/费率从 `src_jbgk_profile` 取；`cost_1y` 用 `fees.holding.cost_profile`（申购费 1 折、按 365 天摊薄）。

| 1 年最大回撤 | **4.96%** | **0.31%** | 约 16 倍 |
| 1 年化波动 | **4.73%** | **0.61%** | 约 7.8 倍 |
| 持有 1 年总成本 | 1.05% | 0.65% | +0.40pp |
| 规模 | 0.52 亿元 | 10.81 亿元 | 约 1/21 |

关键不是“偏债混合收益差”，而是**哪几条线在杀**：MDD、夏普、Calmar、日胜率是主要杀手，波动线反而有 57% 通过。债基的 MDD 2% 是“低波债”的绝对底线；偏债混合的 P25 已经是 2.69%，一半以上产品天然过不了。这不是阈值松紧问题，是资产类别不同。

- 基础门禁通过（L5.5 且无 reason）**9 只**；
- 8 条固定线全过 **2 只**：012334（6 个月持有，L3）、009767（3 个月持有，L5.5）；
- 同时过固定线与申赎门禁的只有 **009767 安信平稳双利 3 个月持有 C**（规模 6.44 亿、cost 0.80%、年化 4.10%、夏普 2.19、MDD 0.47%、Vol 1.12%）。

## 4. 解释

1. **资产类别不同**：偏债混合通常含 10–30% 股票/转债，回撤与波动是债基的数倍；债基固定线（MDD 2%、Vol 6%）是按“纯债/短债”的分布标的，套在含权产品上必然大面积误杀。
2. **固定线的语义不同**：债券筛选的固定线是“灾难过滤器”，不是“选优线”；偏债混合连灾难过滤都过不了，说明它需要一套自己的灾难线（例如 MDD 8%、Vol 8%），而不是把债基线放宽一点点。
3. **结构门禁比指标更硬**：93/196 是持有期/定开，54/196 是规模不足；这两类不是评分能解决的。偏债混合里有大量迷你基金和持有期产品，天然不适合做“随时可申赎”的榜单。
4. **规模口径有水分**：样本规模来自 jbgk 单份额，A/C 可能被拆分（012334 A 0.40 亿 / C 0.04 亿），所以 54 只 L5 里有一部分在家族汇总后可能过线；但 L3 的 93 只不会因为规模汇总而消失。这个偏差只会让“规模问题”看起来更严重，不会改变“指标+持有期”结论。
5. **不是收益差才不并**：即使某年偏债混合收益很好，它的回撤/波动仍会让债基分位池失真；把高 beta 产品混进来，会像 2024–2025 转债牛市那样把榜单推向风格暴露（参见 F5/F6 的教训）。

## 5. 决策

1. **不把偏债混合并入债券 universe，不发布偏债混合榜**；继续留在 `UNCOVERED_SCOPE`，并把它从“2,950 只”更正为最新目录的 **1,475 只**（2026-11-02）。
2. **不实现 `hybrid` 类型插件**。当前 `fundtypes.REGISTRY['hybrid'].implemented=False` 保持不变；只在 gaps 里补上这次试点的量化结论，避免以后重复试点。
3. **如果未来要做**，必须单开 `hybrid_balanced` profile，至少满足：
   - 独立固定线（建议起点：年化 ≥3%、夏普 ≥0.8、Calmar ≥1.0、日胜率 ≥50%、MDD ≤8%、Vol ≤8%、cost_1y ≤1.5%）；
   - 独立分位母体（不能与 bond_* 混池）；
   - 独立榜单（建议 20–30 只，不挤占债券七榜）；
   - 先解决 `run_style` 的 types 过滤、`purge_non_universe` 的误删风险、family 规模汇总、持有期/定开口径；
   - 风格体系至少拆“含权比例/转债暴露”，不能只用一个 `hybrid_balanced`。
4. **研究个案保留**：009767 可作为“低波偏债混合”的观察样本，但不因此开榜。

## 6. 局限

- 200 只随机样本，1 年窗口（2025-11 至 2026-10）；结论对“风险剖面差异”稳健，对“收益中位数”不稳健。
- 规模是 jbgk 单份额口径，未做 family 汇总；A/C 拆分可能高估规模不足的比例。
- 申赎状态固定 `confirmed_yes`，没有验证真实可投性；L2 在试点中为 0 是人为设定。
- 只覆盖 `混合型-偏债`，不含 `混合型-平衡`（72 只）、`混合型-绝对收益`（38 只）；后者可能更接近“固收+”，但同样不是债券型。
- 未扣赎回费、未考虑持有期到期后的实际退出；未做幸存者偏差修正。
